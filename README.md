# ねこ日記

猫の写真と短い日記を残すWebアプリのMVPプロトタイプ。

公開URL: https://kagetora718.github.io/neko-diary/

## 画面

1. **ホーム** — 登録した猫をカードで表示。猫の追加もここから。
2. **猫ごとの日記一覧** — その猫の記録を新しい順に表示。
3. **新規記録** — 日付・写真（最大5枚）・日記を入力して保存。

## 技術構成

- Next.js（App Router）を静的サイトとして書き出し（`output: 'export'`）
- データは **ブラウザの localStorage のみ**。サーバーもDBもなし
- 写真は保存前に長辺800pxまで縮小してJPEGにする（localStorageは約5MBまで）
- 状態管理ライブラリ・UIフレームワークは使わない

## 制約

- データは端末のブラウザ内にのみ保存される。端末やブラウザを変えると引き継がれない
- Safariのプライベートブラウズでは保存できない場合がある
- 写真を入れすぎると容量上限に達する。その場合は保存時にメッセージが出る

## 開発

```
npm install
npm run dev
```

`main` にpushすると GitHub Actions が自動でビルドし、GitHub Pages に公開する。
